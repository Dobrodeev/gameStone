## Задача 1. Вывод чисел от A до B

Пользователь вводит два положительных числа `A` и `B`, программа печатает на экран все числа от `A` до `B` включительно, причём каждое столько раз, каково значение этого числа.

**Пример:** `A = 2`, `B = 5`.

Вариант 1:

```
22
333
4444
55555
```

Вариант 2:

```
2345
2345
345
45
5
```

Сделать таблицу перевода градусов Цельсия в градусы Фаренгейта.

**Этап 2:** реализовать таблицу через функцию, в которую передаются параметры:

- стартовое значение;

## Задача 4. Сортировка двумерного массива

В файле `sort.php` находится массив, каждый элемент которого состоит из трёх значений. Массив нужно отсортировать по следующим правилам:

1. по возрастанию, в алфавитном порядке, по первому значению (`[0]`);
2. если первые значения совпадают — по возрастанию суммы второго и третьего значений (`[1] + [2]`).

**Пример.** Исходный массив:

```
g, 6, 3
f, 8, 6
a, 5, 3
f, 2, 5
```

Результат сортировки:

```
a, 5, 3
f, 2, 5
f, 8, 6
g, 6, 3
```

Решение: [`Sorts/SortClass.php`](Sorts/SortClass.php), исходный массив — [`Sorts/sort.php`](Sorts/sort.php).

## Задача 5. Проверка robots.txt по чек-листу с выгрузкой в Excel

Сделать форму, в которую пользователь вводит адрес сайта. Скрипт загружает файл `robots.txt` этого сайта, проверяет его по чек-листу и выводит результат в виде таблицы со статусом каждой проверки (`OK` или `Error`).

Чек-лист:

| № | Проверка | Условие успешной проверки |
|--:|----------|---------------------------|
| 1 | Наличие файла `robots.txt` | файл существует |
| 2 | Указание директивы `Host` | директива `Host` есть в файле |
| 3 | Количество директив `Host` | в пределах одного блока `User-agent` директива `Host` указана не более одного раза |
| 4 | Размер файла `robots.txt` | не больше 32 КБ |
| 5 | Указание директивы `Sitemap` | директива `Sitemap` есть в файле |
| 6 | Код ответа сервера для `robots.txt` | сервер отвечает кодом `200` |

Результаты проверки нужно выгрузить в файл Excel (`.xlsx`) с таблицей из столбцов «№», «Название проверки», «Статус». Статус `OK` и статус `Error` выделяются разными цветами.

Решение: [`infoRobots/infoRobots.php`](infoRobots/infoRobots.php) — форма и проверка, [`infoRobots/infoRobotsExcel.php`](infoRobots/infoRobotsExcel.php) — выгрузка в Excel (библиотека [PhpSpreadsheet](https://github.com/PHPOffice/PhpSpreadsheet), нужен PHP 8.6+, перед запуском выполнить `composer install` в папке `infoRobots`).

## Задача 6. Вычисление факториала

Сделать форму, в которую пользователь вводит натуральное число `n`, и вывести его факториал:

```
n! = 1 × 2 × 3 × … × n
```

Факториал нужно вычислить двумя способами:

1. с помощью цикла;
2. с помощью рекурсии.

**Пример:** `7! = 5040`, `8! = 40320`.

Решение: [`Factorial/factorialForm.php`](Factorial/factorialForm.php) — форма ввода, [`Factorial/factorial_handler.php`](Factorial/factorial_handler.php) — обработчик, сами вычисления — методы `factorialLoop()` и `factorialRecursive()` в [`Sorts/RecursivClass.php`](Sorts/RecursivClass.php).
