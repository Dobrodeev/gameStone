## Задача 0. Пересечение двух окружностей

Сделать форму ввода данных двух окружностей: координаты центра и радиус.
Определить количество точек пересечения окружностей.

## Задача 1. Вывод чисел от A до B

Пользователь вводит два положительных числа `A` и `B`, программа печатает на экран все числа от `A` до `B` включительно, причём каждое столько раз, каково значение этого числа.

**Пример:** `A = 2`, `B = 5`.

Вариант 1:

```
22
333
4444
55555
```

Вариант 2:

```
2345
2345
345
45
5
```

## Задача 2. Таблица перевода градусов Цельсия в Фаренгейты

Сделать таблицу перевода градусов Цельсия в градусы Фаренгейта.

| Degrees Celsius | Degrees Fahrenheit |
|----------------:|-------------------:|
| 0.00            |                    |
| 20.00           |                    |
| 40.00           |                    |
| 60.00           |                    |
| 80.00           |                    |
| 100.00          |                    |

Формула расчёта:

```
F = 9 / 5 × C + 32
```

**Этап 2:** реализовать таблицу через функцию, в которую передаются параметры:

- стартовое значение;
- шаг;
- количество строк, которые нужно отобразить.

## Задача 3. Переворот строки с заданной позиции

Дана строка `abcdefkgsfkgjskhhjkjkhh`.
Начиная с заданной позиции (например, 4), перевернуть оставшуюся часть строки задом наперёд.

**Результат:** `abcdhhk...e`
